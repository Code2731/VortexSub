# 문장 끝 마침표 갱신 묶기 — P2.2 제한 후보

2026-10-03 실시간 앱의 읽기 보호는 줄 표시기가 담당한다. 마침표 후보만 별도로
0.75초까지 묶으며 이후 1.25초 일반 교체 대기는 중복 적용하지 않는다.
옵션은 계속 기본 끔이며 아래 비교 수치는 이전 0.25초 기본 정책의 기록이다.

## 사용

라이브 앱 설정의 **마침표 갱신 묶기 · 실험 / 기본 끔**을 세션 시작 전에 선택한다.
세션 실행/일시정지 중에는 변경할 수 없다. 추가 번역 요청·두 번째 모델 합의는 없다.
원문 표시와 기존 부분 번역 설정은 독립적이다.

## 적용 범위

* 유효한 두 부분 번역이 같은 session/epoch/segment·단위 위치이고 번역 원문과
  보호 prefix가 정확히 같아야 한다. 새 request만 대상으로 한다.
* 번역 본문이 같고 끝의 **단일 `.` 또는 `。`**만 다른 경우에 한정한다.
  말줄임표, 물음표/느낌표, 숫자가 있는 번역, 단어·공백·말투 변경은 추가 대기하지 않는다.
* 첫 번역·새 단위·원문 prefix 무효화·번역 소실·최종 전체 번역은 추가로 보류하지 않는다.
  최종 번역에는 강제 target prefix를 주지 않는다.

현재 draft 카드의 대상 갱신은 기존 표시 시각부터 0.75초까지 최신 하나로 묶는다.
새 후보로 대기 기한을 계속 연장하지 않는다. 실제 화면의 읽기 보호는 줄 표시기가
담당한다. 반복 조회만으로 표시 시간이나 읽기 만료를 늘리지 않는다.
0.1초 앱 timer가 기한을 처리하므로 실제 적용은 다음 tick/UI 처리까지 늦을 수 있다.

새 어휘/확정 교정이 오면 마침표 대기를 교체하거나 취소하고 기존 우선 경로를 따른다.
Pause/Stop/context 변경/모델 설정 변경 시 카드와 대기를 함께 비운다.

## 진단과 비교

기존 자막 timing 옵션에서 `CosmeticDeferred`와 `policy_not_before_s`를 기록한다.
원문·번역 문자열은 일반 로그에 저장하지 않는다. 집계 도구는 이 관찰 건수를 별도로 센다.

```powershell
scripts/compare-fixed-translation.ps1 -Trace <source-trace.json> -Rounds 1
```

기존/후보 두 deck에 **동일 history와 동일 시각**을 공급한다. 모델 추론은 한 번만 한다.
첫 카드 적용 차이, 실제 번역 카드 변경 snapshot, 후보 대기 관찰을 기록한다.
이것은 렌더링이나 새로운 의미 오류의 독립 평가가 아니다. 최종/중간 내용은 Git 제외
replay 자료에서 함께 검토한다.

## 범위를 제한한 이유

한국어의 문자열 합의는 같은 의미를 보장하지 않는다. 말투·단어·조건의 일반 수정에서
이미 보인 본문을 고정하면 필요한 교정까지 막을 수 있다. 현재는 의미를 판정할 근거가
부족하므로 target prefix 동결을 구현하지 않았다. 이 후보는 표현이 그대로인 마침표
갱신만 다루며, 남은 ASR/번역 지연을 줄이는 정책으로 주장하지 않는다.

효과가 관찰되지 않거나 필요한 교정이 늦으면 채택하지 않는다. 기본값은 꺼짐이다.
