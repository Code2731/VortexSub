# v1.0 준비 로드맵

갱신일: 2026-10-13. 현재 소스 기준 HEAD: `15f1db0`.
이후 UI·자막 배정·자동 검증·근거 문서는 미커밋이다. 다른 PC에는 아직 전달되지 않았다.
이 문서는 기존 [M0~M5 로드맵](08_ROADMAP.md)의 현재 점검표다.
지원 범위나 수용 기준을 변경하지 않는다. 기준은 [요구사항](02_REQUIREMENTS.md)과
[출시 검증](07_VALIDATION.md)을 따른다.

## 현재 위치

Windows의 캡처·VAD·Whisper·로컬 HTTP 번역·자막 경로를 연결했다.
세션 제어, 기록, 원문 TXT/SRT, 두 줄 표시, 설정 복원과 오류 복구도 구현했다.
최근 앱 내부 키보드·기록 41개와 설정·연결 복구 60개 검사가 통과했다.
실제 Hy-MT2 번역의 연속 문장·긴 문장·부분 원문 수정 화면도 확인했다.
최근 모델 화면 확인에는 실제 음성·VAD·ASR을 사용하지 않았다.

현재는 **Windows 개발판의 M2~M3 구현과 사용성 보완 단계**다.
양 OS의 M0~M3 gate는 완료되지 않았다. M4~M5 제품 통합·출시 gate도 남아 있다.
배치 런처가 설치된 서버를 실행하는 기능은 관리형 제품 설치 완료와 다르다.

## 남은 순서

| 순서 | 단계 | 작업 | 종료 조건 |
|---|---|---|---|
| 1 | 개발판 수용 마무리 / M3 | 의미 반박의 수정 대기 정책 검토, 기본 모델·옵션 확정, 자연 음성 품질·지연 평가, 30분 E2E와 장애 복구 | 확정한 표시 정책의 근거, 언어별 결과, 누락·오류·자원 추이와 P0 판정 기록 |
| 2 | 설치·실행 제품화 / M4 | 앱의 모델 설치·동의·취소·해시·삭제, 검증 런타임 준비, 인증·health·자식 프로세스 정리 | 별도 번역 서버 도구를 사용자가 설치하지 않아도 모델 준비→번역→종료 가능 |
| 3 | 오버레이·사용성 마무리 / M3~M4 | 글꼴 크기 조절, 클릭 통과·잠금 해제, DPI·모니터 제거 복구, 원문+번역 SRT, 실제 키 입력·접근성 | 요구 ID `UI-002~004`, `HIS-002`, `NF-007`의 해당 범위 확인 |
| 4 | 출시 안정성 / M5 | 2시간 연속 사용, 100회 세션 제어, 서버 중단·장치 분리·메모리 압박, 게임 동시 실행 | crash/deadlock·고아 프로세스 없음, 대기와 메모리 증가 없음, 게임 영향과 누락 공개 |
| 5 | 패키징·출시 판정 / M5 | SDK 없는 환경 설치, native 의존성·업데이트·설정 호환, 사용 안내·알려진 문제·최종 회귀·소스 동기화 | 설치→모델 준비→전사→번역→종료 재현, 기준별 결과와 미달 대응 기록 |

수용 검증은 기존 순서대로 진행한다. M3 gate 미충족 상태를 M4 통합 승인으로 해석하지 않는다.
독립적인 UI 정리와 배포 설계는 병행할 수 있다.
2026-10-07 UI-002의 글꼴 크기 조절·저장 복원을 구현했다. 앱 빌드는 통과했다.
화면·실제 키 입력과 복원 검증은 남아 있다. 오버레이·사용성 단계 전체 완료는 아니다.
[글꼴 조절 근거](evidence/overlay-font-size-windows-20261007.md).
2026-10-08 세 글꼴의 모의 화면을 확인했다. Windows 잠금·메인 해제를 구현했다.
창 속성 전환을 확인했다. 실제 클릭 전달·메인 입력·macOS는 아직 검증하지 않았다.
[후속 화면 근거](evidence/overlay-appearance-lock-windows-20261008.md). UI-003 gate는 남아 있다.

## 플랫폼과 완료 기준

기존 지원 목표는 Windows와 Apple Silicon macOS다.
macOS는 ScreenCaptureKit 브리지·권한·번들·실시간 전사·번역·화면·패키징을 진행해야 한다.
현재 Mac 실기기 검증 결과는 없다. Windows 결과로 macOS 지원을 확정하지 않는다.
Mac 환경이 확보되면 플랫폼 위험 검증부터 진행한다.
Windows 우선 v1.0을 원할 경우 지원 범위·gate 변경을 별도로 확정해야 한다.

기존 지연 목표는 원문 final P95 2초, 번역 final P95 4초,
긴 발화 partial 첫 표시 P95 2.5초다. 마지막 음성/첫 음성 기준을 구분한다.
영어·일본어→한국어 각 50개 대사에서 의미 전달 45개 이상과
숫자·부정·명령 관련 중대 오류 0개가 내부 목표다.
관리형 메모리·무음·Stop·게임·배포 기준도 `07_VALIDATION.md`에서 함께 판정한다.
짧은 화면 관찰 수치를 이 목표의 통과 증거로 사용하지 않는다.

완료율과 날짜는 확정하지 않는다. 남은 제품 기능과 실기기 검증 범위가 크다.
로드맵 최초 점검에서는 빌드·테스트·모델 추론을 실행하지 않았다.
후속 철회 정책 라운드는 앱 빌드와 실제 모델 화면 실행을 완료했다. 자동 테스트는 실행하지 않았다.

## 보류와 제외

Laya 시작 시점 판단은 사용자 지시로 진행하지 않는다.
캡처 시작/백신 승인 원인 조사는 사용자 지시로 보류한다. 새 요청 없이 재개하지 않는다.
실제 E2E에서 캡처가 가능해야 한다는 수용 조건은 그대로 남는다.
새 모델 연구는 병목 근거가 있을 때만 검토한다. v1.0의 자동 선행 작업으로 추가하지 않는다.
