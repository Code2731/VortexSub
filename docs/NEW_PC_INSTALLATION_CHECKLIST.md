# 새 PC 설치 체크리스트

갱신일: 2026-11-01. 이 문서는 새 PC에서 EchoSub를 설치하고 검증하는 절차를 기록한다.

## 사전 준비

### 시스템 요구사항
- **OS**: Windows 10/11 (x64)
- **RAM**: 8 GB 이상 (CPU 전사), 16 GB 이상 (GPU 번역)
- **저장 공간**: 5 GB 이상 (모델·런타임 포함)
- **GPU** (선택): NVIDIA CUDA 지원 GPU (번역 사용 시)

### 다운로드 파일
- `EchoSub.Desktop.exe` - 앱 실행 파일
- `first-run-policy.json` - 카탈로그 (앱에 내장)

## 설치 절차

### 1. 앱 설치
1. `EchoSub.Desktop.exe`를 다운로드한다.
2. 실행 파일을 원하는 위치에 저장한다.
3. 실행 파일을 더블클릭하여 앱을 시작한다.

### 2. 첫 실행 설정
1. 앱이 시작되면 "설치" 탭을 확인한다.
2. **모델 조합 선택**:
   - ★ 표시가 있는 프로필이 권장 프로필이다.
   - `base-source-cpu`: 기본 전사 프로필 (CPU 실행)
   - `base-hymt2-cuda`: GPU 번역 프로필 (CUDA 필요)
3. **음성 언어 선택**: en, ja, ko, zh 중 선택한다.
4. **동의 확인**: 다운로드·설치에 동의 체크박스를 확인한다.
5. **설치 시작** 버튼을 누른다.

### 3. 다운로드·설치
1. 진행률 바가 표시된다.
2. 각 자산이 다운로드되고 검증된다.
3. 설치가 완료되면 "✅ 설치 완료!" 메시지가 표시된다.

### 4. 첫 자막 확인
1. "자막" 탭으로 이동한다.
2. 출력 장치와 음성 언어를 선택한다.
3. "자막 시작" 버튼을 누른다.
4. 음성을 재생하고 자막이 표시되는지 확인한다.

## 검증 항목

### 기본 기능
- [ ] 앱이 정상적으로 시작된다.
- [ ] "설치" 탭이 표시된다.
- [ ] 권장 프로필이 ★로 표시된다.
- [ ] 모델 다운로드가 완료된다.
- [ ] 설치 후 "자막 시작"이 가능하다.
- [ ] 자막이 화면에 표시된다.

### 번역 기능 (GPU 프로필)
- [ ] 번역 서버가 시작된다.
- [ ] 원문이 한국어로 번역된다.
- [ ] 번역 자막이 표시된다.

### 오프라인 재실행
- [ ] 인터넷 연결 없이 앱을 다시 실행한다.
- [ ] 자막이 정상적으로 작동한다.

### 오류 처리
- [ ] 다운로드 취소가 정상적으로 작동한다.
- [ ] 저장 공간 부족 시 오류 메시지가 표시된다.
- [ ] 권한 거부 시 안내 메시지가 표시된다.

## 문제 해결

### 다운로드 실패
- 인터넷 연결을 확인한다.
- 방화벽 설정을 확인한다.
- 다른 네트워크에서 시도한다.

### 설치 실패
- 저장 공간이 충분한지 확인한다.
- 설치 경로에 쓰기 권한이 있는지 확인한다.
- 다른 경로로 설치한다.

### 자막 미표시
- 출력 장치가 올바른지 확인한다.
- 음성 볼륨을 확인한다.
- 다른 장치로 변경하여 시도한다.
