# 01. 개념설계

## 1. 제품 정의

**시스템에서 재생되는 말소리를, 사용 중인 앱을 바꾸지 않고 읽을 수 있는 자막으로 전환한다.** 필요하면 다른 언어로 번역한다.

작동 예: 일본어 영상 재생 → EchoSub에서 일본어/한국어 선택 → 시작 → 원문과 한국어 자막이 화면 위에 나타남 → 놓친 대사는 기록 창에서 확인.

기본 입력은 PC 시스템 오디오다. 마이크 받아쓰기 앱, 웹페이지 자막 추출기, 영상 편집기의 자막 생성 기능과 구분한다. 영상 사이트의 자막 제공 여부와 독립적인 오디오 처리 파이프라인을 만든다. 콘텐츠가 OS 캡처 경로에서 제공되지 않는 경우까지 포착한다고 보장하지는 않는다. [R01]

## 2. 주요 사용 시나리오

| 시나리오 | 기대하는 동작 | 우선순위 |
|---|---|---|
| 해외 영상·방송 시청 | 영어/일본어 음성을 한국어 자막으로 표시 | P0 |
| 개발 강의·튜토리얼 | 원문과 번역을 동시에 읽고 세션 자막을 저장 | P0 |
| 게임 대사 | 창모드/테두리 없는 창에서 자막 오버레이 사용 | P0 |
| 이미 한국어인 영상 | 한국어 받아쓰기만 사용 | P0 |
| 특정 앱만 듣기 | 브라우저만 또는 게임만 캡처 | P1 |
| 회의에서 마이크와 상대 음성 합치기 | 양방향 입력·화자 분리 | P2 |

사용 대상 앱의 콘텐츠를 앱 내부에서 열 필요는 없다. 외부 플레이어의 재생/탐색을 제어하지 않는다.

## 3. 개발 MVP의 범위

- Windows 11 x64, macOS Apple Silicon에서 시스템 오디오 캡처.
- 시작·일시정지·재개·종료, 캡처 상태/오디오 레벨 표시.
- 영어·일본어·한국어 원문 전사. 영어/일본어 → 한국어 번역을 우선 수용 테스트 대상으로 삼음.
- 원문 부분 자막과 확정 자막을 구분. 번역은 확정 원문에만 수행.
- 위치/크기/글자 크기/배경 농도를 조절하는 별도 자막 창.
- 세션 내 기록, 복사, TXT/SRT 내보내기.
- 로컬 번역 서버 연결과 실패 시 원문 전사 유지.
- 짧은 문맥과 작은 모델로 시작하는 저부하 설계.

## 4. 제품 베타의 추가 범위

모델 설치·검증·삭제, 앱 관리형 번역 런타임, Windows/macOS 배포 패키지, 2시간 안정성 시험, 실제 두 플랫폼에서의 기본 기능 동등성을 포함한다. **별도 서버 없이 번역이 되는 단계**를 제품 베타로 구분한다.

## 5. 첫 버전에서 하지 않는 것

음성 합성/더빙, 음성 복제, 화자 식별, 화면 OCR, 영상 파일 편집, 유튜브 자막 수집, 브라우저 확장, 모바일, Linux 제품 지원, 게임 프로세스 주입, 커널 드라이버, 전역 단축키, 클라우드 계정/결제는 제외한다. 앱별 캡처와 사용자 용어집은 후속 기능이다.

## 6. UX의 핵심

사용자는 “언어 선택 → 시작”으로 접근하되 처음에는 모델 설치와 OS 권한을 안내받는다. 내부 엔진 용어보다 “음성 듣는 중 / 인식 중 / 번역 연결 끊김”을 보여준다.

자막 창은 원문과 번역을 같은 대사 단위로 묶는다. 새 원문 아래에 이전 대사의 번역을 잘못 붙이지 않는다. 번역이 밀려도 원문은 계속 나온다. 침묵에는 새 문장을 생성하지 않는다.

## 7. 지연에 대한 제품 정의

실시간은 “음성이 들어오는 동안 처리한다”는 뜻이다. 다른 앱이 이미 재생한 음성을 듣고 자막을 만들므로 원래 영상 자막처럼 항상 선행 표시하거나 완전 동기화할 수 있다고 설명하지 않는다.

초기 성능 목표는 발화 끝에서 원문 확정까지 P95 2초, 번역 확정까지 P95 4초다. 이는 모델이 준비된 기준 장치에서 검증할 목표이며 보장값이 아니다. 지연 측정의 정의는 07번 문서를 따른다.

## 8. 기술 기준안

Rust 공통 엔진과 C# Avalonia UI를 채택하는 설계다. Avalonia의 Windows/macOS 지원이 공통 UI의 기반이며, OS 특수 동작은 별도 어댑터로 둔다. [R03]

초기 ASR 후보는 whisper.cpp의 다국어 Whisper small/base다. Windows GPU와 Apple Silicon 가속 경로를 가진 동일 엔진을 먼저 사용해 플랫폼 간 결과 차이를 줄이는 방향이다. [R04]

번역은 엔진과 모델을 분리한다. 모델은 다운로드 크기만으로 결정하지 않고, 전사와 동시에 실행한 지연·메모리·번역 품질을 측정해 선택한다.

## 9. 프로젝트 독립성

별도 저장소로 만든다. VortexCut과 연관될 수 있는 오디오 처리 개념은 참고하되 기존 코드의 존재·품질·인터페이스를 가정하지 않는다. 공통 라이브러리 추출은 실제 재사용 지점이 확인된 뒤 별도 결정한다.
