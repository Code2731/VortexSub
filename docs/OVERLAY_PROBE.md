# MOCK 오버레이 실행과 검증

T00-04.3 / UI-002·004 / HW-UI01의 기본 창 범위. 실제 ASR·번역과 독립된 샘플이다.

## 실행

저장소 루트에서 `scripts/check.ps1` 후 `scripts/run.ps1`을 실행한다. 메인 창의 **샘플 오버레이 표시** 버튼으로 띄우고 숨긴다. 폭·배경 불투명도 슬라이더로 조절하고, **오버레이 위치 초기화**로 메인 창이 있는 화면의 아래쪽 작업 영역으로 되돌린다. 오버레이 위의 MOCK 줄을 끌어 이동하고 오른쪽 아래 ↘를 끌어 크기를 바꾼다. 메인 창을 닫으면 오버레이와 worker도 종료된다.

## 자동 probe

Windows에서 `scripts/probe-overlay.ps1`을 실행한다. 앱을 빌드하고 짧게 창을 표시한 뒤 HWND 속성, 실제 투명도, 크기·위치 변경, 숨김·재표시를 검사한다. JSON 보고서와 Avalonia 렌더 PNG는 `docs/evidence/T00-04.3-windows-overlay.*`에 저장된다. PNG는 창 내부 렌더이며 게임과의 실제 합성 화면을 증명하지 않는다.

종료 코드 0은 실행 가능한 속성 검사가 통과했다는 뜻이다. `focus_result`가 BLOCKED이면 포커스는 미검증이다. foreground HWND 0을 포커스 유지 성공으로 해석하지 않는다.

## 실제 데스크톱에서 남은 확인

1. 일반 창·테두리 없는 게임 각각에서 자막이 위에 보이는지, 영어/일본어/한국어 글자가 잘리는지 확인한다. 대상 앱·OS·배율을 기록한다.
2. 일반 사용자 세션에서 자동 probe를 실행해 foreground HWND가 존재하고 표시/재표시 전후 동일한지 확인한다. 오버레이 표시 후 다른 앱에서 타이핑하며 클릭·드래그가 입력 포커스를 가져오는지도 확인한다.
3. MOCK 줄 이동, ↘ 크기 조절, 메인 창 슬라이더·숨김·위치 초기화를 직접 조작한다.
4. 메인 창 종료 후 오버레이가 사라지고 새 worker가 남지 않는지 확인한다.

Windows 100/150/200%·다중 화면, 게임별 합성, Mac Spaces는 별도 실제 결과가 필요하다. 클릭 통과와 잠금 복구의 전체 검증은 M3/M4 범위다. T00-04.3 전체 상태는 아직 PARTIAL이다.
