# 02. 제품 요구사항과 지원 범위

`MUST`는 해당 단계의 필수 조건, `SHOULD`는 기본 구현 방향, `MAY`는 선택 기능이다. P0=개발 MVP, P0B=제품 베타, P1=후속이다.

## 1. 플랫폼 기준

| 대상 | 제품 기준 | 실제 검증 |
|---|---|---|
| Windows | Windows 11 24H2 이상, x64 | RTX 3080 10GB PC 우선. CPU·RAM·드라이버 버전은 측정 시 기록 |
| macOS | macOS 15 이상, Apple Silicon | M3 Pro 36GB 우선. 실제 OS 버전은 착수 시 확인 |
| Linux | 아키텍처에서 확장만 고려 | 제품 지원·패키징·PipeWire 구현은 후속 |
| Windows ARM / Intel Mac | 초기 지원 대상 아님 | 빌드 가능 여부와 제품 지원을 구분 |

위 OS 버전은 이 프로젝트의 지원 범위를 좁히기 위한 선택이다. 개별 API의 절대 최소 버전을 의미하지 않는다. Avalonia가 공표한 지원 단계와 외부 oMLX의 OS 조건은 R03/R09를 확인한다.

## 3. 범위가 다른 기능은 capability로 표현

- Windows MVP는 `output_device_selection=true`, macOS MVP는 `false`다.
- macOS의 시스템 믹스 수집을 특정 스피커 장치별 loopback과 동일하게 설명하지 않는다.
- Windows 기본 장치 전환은 기본 장치 추종 모드에서만 자동 처리한다. 고정 장치가 사라지면 다른 장치를 몰래 듣지 말고 일시정지한다.
- macOS 화면/앱 필터는 OS별 의미가 있다. 앱 오디오 필터와 개별 창 필터를 같은 것으로 취급하지 않는다. [R02]
- 오버레이는 일반 창·테두리 없는 창을 기본 수용 대상으로 한다. 독점 전체화면 위 표시와 보안 데스크톱 표시는 MVP 보장 범위가 아니다. 실제 앱 조합별 결과를 기록한다.

## 5. 데이터 처리 기본값

원본 음성 파일은 저장하지 않는다. 세션 텍스트도 사용자가 내보내기 전에는 디스크에 저장하지 않는다. 진단 로그에는 상태·시간·오류 코드·모델 식별자만 남긴다. 외부 로컬 서버의 자체 로그/프롬프트 캐시는 이 앱이 통제할 수 없으므로 해당 백엔드의 저장 정책과 구분한다. oMLX는 자체 SSD 캐시 기능을 제공한다. [R09]

## 6. 제품 완료의 의미

모의 이벤트만 표시됨, 파일 전사만 됨, 한 OS에서만 됨, 외부 서버 연결만 됨은 각각 중간 상태다. 개발 MVP는 양 OS의 **실제 시스템 오디오→원문→로컬 번역→자막**이 연결되어야 완료다. 제품 베타는 여기에 관리형 모델/런타임과 배포·안정성 검증까지 포함한다.
