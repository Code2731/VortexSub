# 06. 화면과 상호작용 명세

## 1. 첫 실행

```text
[무엇을 하고 싶나요?]
  ( ) 원문 자막만 보기
  ( ) 원문 + 한국어 번역 보기

원어: [영어 / 일본어 / 한국어]
음성 모델: [설치할 모델 또는 기존 파일 선택]
번역 엔진: [개발 MVP: 기존 로컬 서버 연결]
          [제품 베타: 앱에서 관리 / 기존 서버]

[권한 확인] [연결 테스트] [시작]
```

처음에는 자동으로 캡처하지 않는다. 모델 다운로드 크기와 로컬 처리 범위를 안내하고, macOS 권한 거부 시 OS 설정으로 이동하는 실제 경로를 버전별로 표시한다. 개발 MVP에서는 “로컬 서버를 먼저 실행해야 번역 가능”을 분명히 알린다.

## 2. 메인 창

기준 폭 880 DIP, 높이 620 DIP 정도의 제안이며 반응형 레이아웃을 쓴다. 한국어 UI를 먼저 제공하고 모든 문구를 리소스로 분리한다.

상단: 세션 상태 / 원어 / 번역어 / 시작·일시정지·종료.
중앙: 최근 자막 카드 목록. 각 카드에 원문, 번역, 시간, partial/확정/번역 실패 표시.
하단: 오디오 레벨, 처리 지연, 번역 연결 상태, 프리셋.
설정: 캡처, 모델, 번역 서버, 자막 표시, 기록·개인정보, 진단 탭.

숫자와 상태가 없어서 멈췄는지 모르는 화면을 피한다. `소리 입력 없음`과 `음성은 있지만 인식 중`을 구분한다. 번역 서버만 끊긴 경우 원문이 계속 나옴을 보여준다.

## 3. 자막 오버레이

- 별도 투명/반투명 최상위 창. 기본 위치는 선택한 화면 아래쪽 안전 영역.
- 원문 1–2줄, 번역 1–2줄. 긴 문장은 font를 끝없이 줄이지 말고 줄바꿈/카드 교체를 사용한다.
- 기본 font size 26 DIP, 사용자 설정 16–48 DIP. 한글/일본어 glyph fallback을 검증한다.
- 원문/번역을 같은 segment 카드로 묶는다. 늦은 번역이 오면 해당 카드만 갱신한다.
- 화면에는 최신 2개 카드까지. 이후 늦게 도착한 이전 카드 번역은 기록 창만 갱신한다.
- 카드 표시 수명 기본 5초. 늦은 번역을 받더라도 무한히 표시 시간을 연장하지 않는다.
- partial은 “인식 중” 표식 또는 시각적 구분이 있다. 색만으로 상태를 구분하지 않는다.
- drag/resize는 잠금 해제 상태에서만 가능. 잠금 상태의 실제 클릭 통과는 OS 어댑터로 검증한다.

새 segment가 시작될 때 이전 segment의 번역을 새 원문의 번역인 것처럼 재사용하지 않는다. `번역 중`은 빈 공간이나 상태 표식으로 표시한다.

Avalonia의 일반적인 투명 창과 플랫폼별 native 창 동작은 구분한다. Windows의 투명 효과와 macOS 지원 범위가 같지 않다. [R03]

## 4. 플랫폼 창 동작

### Windows

일반 데스크톱과 테두리 없는 게임 창을 첫 검증 대상으로 한다. 작업표시줄 노출, 포커스 탈취 방지, DPI 100/150/200%, 다중 모니터 좌표를 테스트한다. UI 프레임워크 hit test off와 OS click-through는 다른 계층이므로 실제 뒤 앱 클릭으로 확인한다.

### macOS

Spaces, Mission Control, 전체화면 Safari/영상 앱에서 overlay 위치와 창 레벨을 검증한다. 지원되지 않는 조합은 자동으로 보장한다고 쓰지 않는다. native 창 레벨/collection behavior를 플랫폼 어댑터에 둔다. 필요하지 않은 접근성 권한은 요구하지 않는다.

M0에서 창 표시 PoC를 기록하고, 클릭 통과와 fullscreen 동작은 제품 베타의 기기별 수용 시험에서 확정한다.

## 5. 필수 복구 동선

| 상황 | 화면 | 행동 |
|---|---|---|
| 음성이 재생되지 않음 | “소리 입력을 기다리는 중” | 시작 버튼을 실패 상태로 바꾸지 않음 |
| macOS 권한 거부 | “시스템 오디오 접근 권한이 필요합니다” | 설정 열기 / 다시 확인 |
| 출력 장치 분리 | “선택한 장치가 연결 해제되었습니다” | 장치 선택 / 재개 |
| ASR 모델 없음 | “음성 모델을 선택하세요” | 파일 선택 또는 모델 설치 |
| 로컬 서버 중단 | “번역 연결이 끊겼습니다. 원문 자막은 계속 표시됩니다” | 재연결 / 전사 전용 |
| 모델이 너무 느림 | “처리가 지연되어 일부 번역을 건너뛰었습니다” | Economy 제안 / 현재 설정 보기 |
| worker 종료 | “음성 엔진이 종료되었습니다” | 진단 보기 / 엔진 다시 시작 |
| 모델 다운로드 취소 | “설치를 취소했습니다” | 재시도. 모델 설치 완료로 표시하지 않음 |

## 6. 기록과 설정

세션 기록은 마지막 1,000대사를 기본으로 하며 상한 도달 시 오래된 항목이 사라질 수 있음을 표시한다. 중요한 세션은 사용자가 직접 내보낸다. 자동 저장은 P1이다.

설정창에는 실제 backend/model ID, ASR 모델, 활성화된 CPU/CUDA/Metal 경로를 표시한다. GPU를 사용하지 않는데 GPU 가속 켜짐으로 표시하지 않는다. 자원 측정을 지원하지 않는 OS 항목은 `측정 불가`로 둔다.

## 7. 트레이와 종료

MVP는 메인 창을 닫을 때 완전히 종료한다. 제품 베타에서 트레이/메뉴바 유지 옵션을 제공하되, 첫 사용에 닫기 동작을 설명한다. 클릭 통과 오버레이를 만들기 전에 반드시 메인 창/트레이에서 잠금 해제할 수 있는 경로를 제공한다.

전역 단축키는 후속이다. 첫 버전에서는 운영체제별 단축키 권한·충돌 문제를 추가하지 않는다.
