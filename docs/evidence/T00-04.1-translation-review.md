max_tokens 256, 단일 요청. 로그에서 CUDA 37/37 레이어 offload 확인.

## 판단 및 후속

실행 후보는 유지하고 **품질 채택은 보류**한다. `TR-001/002`와 M3
T03-01/03에서 귀환/출발, before/after/until, 숫자·단위, 방패/보호막
용어를 포함하는 독립된 표본으로 재평가한다. 프롬프트·문맥·용어집 또는
후보 변경을 비교하고 동일 표본만 반복해 품질을 주장하지 않는다.
단독 번역 실행만 확인했으며 ASR 동시 부하·게임 공존은 T00-04.4/M5다.

원본 입력: `benchmarks/translation-fixtures.json` (SHA-256
`eab4cb74b784705ee212329d26ac7df5eae33cc709799a37bfff3d8f6a860314`).
전체 결과와 native 로그: 무시된 `benchmarks/results/translation-local/`.
서버 EXE SHA-256: `8ef22515398d453b2e1e3557726e32a33c94f9df230272bfc439a74b709997c9`.
모델 revision/hash/license는 `benchmarks/model-downloads.json`에 고정돼 있다.

최종 입력 검증·실행 스크립트로 `translation-local-20260930-065636`에서
20건을 재실행했다. 번역 문자열 차이는 0건으로 위 의미 검토는 그대로
적용된다. 재실행 중앙값 121.62ms, p95 147.60ms, 범위 85.52~291.08ms,
서버 준비 1950ms였다. 이는 정식 성능 반복 시험이 아니며 최종 hash·집계는
`T00-04.1-windows-summary.json`에 보존했다. 두 실행 모두 소유 서버 종료와
임시 API key 파일 제거를 확인했다.
