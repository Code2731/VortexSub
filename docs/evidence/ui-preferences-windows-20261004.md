# 사용자 설정 보관과 준비 안내 (2026-10-04)

## 변경

실시간 앱은 `%LOCALAPPDATA%/EchoSub/settings.json`을 읽는다.
설정 탭의 **설정 저장** 버튼과 정상 종료 시점에 설정을 저장한다.
저장 항목은 음성 언어, 출력 장치 ID, 자막 창 폭, 배경 불투명도,
원문 표시, 부분 전사, 부분 번역, 마침표 갱신 묶기다.
번역 모델·입력 프로필·문맥 설정은 기존 런처와 worker 설정을 따른다.
지연 로그 기록과 세션 시작은 자동으로 복원하지 않는다.

설정 파일은 버전과 크기를 확인한다. 최대 크기는 16 KiB다.
언어와 숫자 범위를 보정한다. 부분 번역이 켜졌으면 부분 전사도 켠다.
저장은 같은 폴더의 임시 파일을 작성한 뒤 교체한다.
읽기 실패는 기본값으로 복구한다. 저장 실패는 앱 설정 탭에 안내한다.
저장한 출력 장치가 현재 목록에 없으면 기본 장치를 선택한다.
장치 목록을 얻지 못한 실행은 저장한 장치 ID를 덮어쓰지 않는다.
모의 실행은 개인 설정을 읽거나 저장하지 않는다.

메인 화면에 연결, 음성 인식, 번역 준비 안내를 추가했다.
시작 버튼이 비활성화됐으면 준비 완료로 안내하지 않는다.

## 확인

Windows x64에서 아래 빌드는 경고 0개, 오류 0개로 통과했다.

```powershell
dotnet build apps/EchoSub.Desktop/EchoSub.Desktop.csproj --no-restore
```

명시적 모의 worker로 앱을 실행해 7개 화면 렌더를 저장했다.
메인, 설정 하단, 최소 크기 메인 화면을 직접 확인했다.
설정 저장 안내와 준비 안내가 보이며 주요 제어가 최소 크기에도 들어간다.
결과는 Git 제외 `benchmarks/results/ui-preferences-20261004/`에 있다.
마지막 빌드에는 장치 ID 보존과 실제 준비 상태의 추가 분기 보강을 포함했다.
이 보강은 모의 화면의 내용에는 영향을 주지 않는다.

## 남은 확인

이번 캡처는 개인 설정 저장을 실행하지 않았다.
실제 앱 재실행에 따른 설정 복원, 파일 접근 실패, 장치 제거 상황은
실행 검증하지 않았다. 자동 회귀 테스트와 실제 음성 처리는 미실행이다.
화면은 Avalonia 렌더이며 운영체제 합성 화면은 아니다.
