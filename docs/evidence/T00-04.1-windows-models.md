## ASR

모델당 context/state 한 번 생성, 첫 fixture warm-up 한 번 후 21개를
순차 decode했다. 16 kHz mono, 명시적 언어, greedy best_of 1,
no_context, 8 threads. 로그의 CPU/CUDA 사용을 직접 확인한다.
원문을 합친 WER/CER은 영어 whitespace token, 한/일 Unicode scalar 기반이며
소문자·문장부호 제거, CER 공백 제거를 적용한다. 숫자 표기 변환과 NFC/NFKC
정규화는 하지 않는다. 숫자 표기의 오류율과 실제 의미 오류를 구분한다.

최적화 CPU 실행 `asr-cpu-20260930-064943`의 평균:

실행 파일·report·입력 hash와 집계값은
[기계 판독 summary](T00-04.1-windows-summary.json)에 보존했다. 원본
report/native 로그는 무시된 `benchmarks/results/`에 있다. 초기 CUDA 성공
실행도 보존하되 표는 최종 Release 설정 실행을 사용했다.

각 언어 10건을 합친 raw WER은 둘 다 2/72 = 2.78%이며 ten/fifteen을
10/15로 쓴 차이였다. raw 한국어 CER은 base 16/123 = 13.01%, small
14/123 = 11.38%. 실제 단어 오류도 있다: base의 “회복 물약”→“회복 무리하기”,
small의 “가는 게 좋겠어”→“가는 계속했어”. 이 소표본으로 small의 품질
우위를 주장하지 않는다. CPU/CUDA 전사 차이는 별도 summary로 확인한다.

무음에서 두 모델 모두 `[BLANK_AUDIO]`를 반환했다. empty-reference
error rate는 null, unexpected_text는 true다. 이는 실제 발화 환각과
구분해야 할 모델 표식이며, M2의 무음/출력 필터 수용 시험에 추가한다.

## 수정한 실행 실패와 측정 제외

1. bundled Linux ABI bindings의 Windows 구조체 assertion 실패 → LLVM으로
   Windows bindings 생성. 저장소/레지스트리 원본을 임의 수정하지 않았다.
2. VS generator의 CUDA compiler identification 실패 → Ninja 사용.
3. nvcc 기본 sm_52 코드의 CUDA kernel launch 실패 → 실제 GPU compute 8.6
   타깃으로 재빌드. 실패 로그는 `asr-cuda-20260930-064109/native.log`에 보존.
4. 초기 native CPU Release에 `/O2`가 누락됨 → `/O2 /DNDEBUG` 지정.
   최종 CPU build.ninja의 `/arch:AVX2`, GGML_AVX2/FMA/F16C도 확인했다.
   초기 `asr-cpu/`와 `asr-cpu-spotcheck/`의 7~30초 값은 채택 비교에서 제외한다.
   초기 측정 일부는 CUDA 컴파일과 겹쳤다. 최종 CPU 실행은 해당 빌드가
   끝난 후 수행했고 다음 GPU 재빌드 전에 완료됐다.

## 번역·검증·후속

실제 로컬 llama-server의 영어/일본어 각 10건 호출과 의미 검토는
[별도 보고서](T00-04.1-translation-review.md)에 기록했다. 귀환 조건의
중대 오역이 있어 품질 채택은 보류다. ASR 후보도 자연 발화와 동시 부하
자료가 확보될 때까지 제품 기본 모델로 확정하지 않는다.

`scripts/check.ps1` PASS: Rust fmt, 시험 9개, 기본 workspace 빌드,
UI/C# smoke 빌드, Unicode·64요청·종료/worker 죽음 smoke. 번역 .NET 빌드도
경고/오류 0. 기본 빌드의 native feature는 off이므로 실제 native 검증은
별도 모델 실행 결과로 확인한다. 재현 명령은 `benchmarks/README.md` 참고.

load/decode/HTTP 시간을 UI 자막 지연으로 해석하지 않는다. peak working set은
프로세스 누적값이며 VRAM peak가 아니다. T00-04.2의 실제 취소·재시작,
T00-04.4의 5분 동시 부하, M2/M3의 자연/일본어·무음·번역 품질 재평가가
다음이다. Mac 실행과 두 기준 장치·게임 공존은 아직 확인되지 않았다.
