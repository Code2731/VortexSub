# live 표시 연결과 통합 진단 — Windows (2026-10-10)

## 변경

MainWindow의 live 오버레이 카드 전달 3곳을 `SetLiveCards`로 연결했다.
선택된 번역 기록 → Deck → 전달 어댑터 → 새 배정기 → 기존 TextBlock 렌더 경로다.
오버레이 재생성 시 현재 카드를 명시적으로 다시 전달한다.
중지·빈 카드 삭제·세션 변경은 배정기뿐 아니라 어댑터의 세션도 종료한다.
명시적 삭제 뒤 같은 세션으로 재개하는 검사를 추가했다.
모의 표시·기존 회귀·직접 후보 입력은 별도다. 서로 다른 입력 경로의 혼용은 거부한다.

Blocked·BlockEnded·Reused·InputRejected를 통합 진단에 연결했다.
같은 토큰·대기 사유는 Tick마다 다시 발행하지 않는다.
배정·재사용·철회·중지는 기존 대기 구간을 종료한다.
종료 시간은 마지막 유효 Tick까지다. 물리 화면의 대기 시간과 구분한다.
재사용은 증거 종류와 문자 수를 기록한다. 입력 거부는 고정 사유를 기록한다.
진단에는 자막·원문·번역 본문을 저장하지 않는다. `reader = scheduled`로 기존 경로와 구분한다.
기존 128개 비동기 기록 큐를 사용한다. 표시 스레드에서 디스크를 쓰지 않는다.
요약기에 Reused·InputRejected 사건 집계를 추가했다.

중간 자동 실행 도구의 들여쓰기 오류를 수정했다. 수정 뒤 상태·화면·픽셀·진단 검사를 전체 재실행했다.
새 live 검사를 기존 화면 검사에 추가했다. 기존 golden은 변경하지 않았다.
