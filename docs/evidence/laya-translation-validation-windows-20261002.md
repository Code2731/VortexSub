# Laya 번역 출력 검증 결과 (2026-10-02)

## 실행 환경과 자산

Windows / Ryzen 5800X / NVIDIA RTX 3080. 기존 Python 3.12.14,
PyTorch 2.10.0+cu128, Transformers 5.18.0, huggingface_hub 1.33.0 사용.
사용자가 모델·패키지 다운로드와 실제 비교에 동의했다. 기존 환경의 의존성은
변경하지 않고 Laya 0.3.23 wheel을 `models/laya/sdk`에 `--no-deps` 설치했다.

모델은 `convaiinnovations/laya-multilingual`, revision
`e4e9ddf21a7b1903b7acffd8814ad4307bf63a67`, Apache-2.0.
모델/토크나이저/설정 678,201,614 bytes, wheel 286,096 bytes.
`benchmarks/laya-model.json`의 LFS SHA-256/Git blob과 wheel SHA-256을 검증했다.
원본을 보존하고 SDK의 토크나이저 호환 수정은 별도 복사본에서 수행했다.
고정 로컬 파일을 offline 모드로 로딩했다. CUDA fp16 autocast,
compile/TileLang 미사용. 실제 device cuda, CPU 대체 없음.

## 자료와 대조군

12개 작성 원문에 충실한 번역과 오류 번역 하나씩, 총 24개 고유 사례다.
귀환/출발, 엔진/방어막 행동 반전, 일본어 귀환은 이전 관찰 출력을 재사용했다
(영어 귀환의 존대 종결만 줄였다).
나머지는 부정·전후·only-if/unless·방향·수량·비교 경계·사족을 통제한 합성 오류다.
수량 13/30→13/20은 관찰 오류 유형을 작성 문장에 적용했으며 실제 모델 출력으로
표기하지 않았다. 모호한 take→consume 해석은 제외했다. 평가 label은 모델에
전달하지 않았고 첫 추론 전에 고정했다. 대표성 있는 품질 benchmark는 아니다.

각 원문/번역 쌍에 여섯 `choice` 질문을 한 호출로 전달했다:
전체 의미, 행동/주체/부정, 대상/방향, 수량, 시간/조건/비교 경계, 번역만 출력.
A=보존, B=변경/누락/추가를 유지하고 선택지 나열 순서만 A/B와 B/A로 바꿨다.
질문 언어 영어/한국어 × 순서 2개 × 3회 반복이다. 반복은 독립 표본이 아니다.
확률 보정·fine-tuning·평가 자료 기반 임계값 최적화는 하지 않았다.

예비 실행 `laya-translation-20261002-072216-284ccb`의 288호출은 보존했다.
이 실행의 일본어 귀환 원문은 과거 원문에 주어/정중 표현을 확장한 형태였다.
출처를 정확히 맞춰 원문을 `戻るまでドアを開けないで。`로 복구하고, 분류/동일
언어 대조군을 추가한 실행은 `laya-translation-20261002-072456-ee3325`다.
최종 실행 `laya-translation-20261002-072859-5244c9`는 CPU fallback 계수,
옵션 잘림·확률 응답 검사와 실행 소스/manifest 보존을 보완한 후 wrapper로 실행했다.
세 실행에서 일본어 출처 복구 외 품질 label과 검증 질문은 바꾸지 않았다.

최종 명령:

```powershell
./scripts/probe-laya-translation.ps1 -Rounds 3 -Device cuda
```

최종 유효 평가 288호출 = 1,728판단. 응답 오류/잘림 0.
별도 대조군 8호출과 warmup 4호출은 평가 통계에서 제외했다.
원문/번역, 질문, 응답 확률, 메타데이터, 증분 결과는 Git 제외 결과 폴더에 있다.

## 최종 결과

아래 검출/오차단 수는 고유 사례 단위다. 각 결과가 3회 동일하게 반복됐다.

| 질문/순서 | 전체 의미 오류 검출 / 12 | 정상 오차단 / 12 | 호출 중앙값(초) | p95(초) |
|---|---:|---:|---:|---:|
| 영어 A/B | 1 | 1 | 0.0465 | 0.0590 |
| 영어 B/A | 0 | 0 | 0.0455 | 0.0625 |
| 한국어 A/B | 2 | 2 | 0.0465 | 0.0657 |
| 한국어 B/A | 3 | 0 | 0.0472 | 0.0698 |

* 전체 의미 질문의 오류 검출률 0~25%, 정상 오차단률 0~16.7%.
* 조건 오류 6개는 모든 설정에서 조건 질문으로 검출하지 못했다(0/6).
* 영어/일본어 귀환 오류는 모든 설정에서 전체 의미와 조건을 보존했다고 판단했다.
* 엔진/방어막 오류는 한국어 전체 의미 질문이 검출했고, 영어 전체 의미는 놓쳤다.
  대상 질문은 네 설정 모두 검출했다. 부분적으로 유효한 신호도 있었다.
* 관찰 후 확인한 대안 집계인 '여섯 질문 중 하나라도 B'는 검출 2~3/12,
  정상 오차단 0~2/12였다. 이 집계도 배포 규칙으로 채택하지 않았다.
* 선택지 순서 비교 864판단 중 135판단(15.625%)이 바뀌었다.
  고유 비교 288개 중 45개가 바뀐 것이 3회 반복된 결과다.

기본 분류 대조군은 영어/한국어 환불 및 앱 충돌 네 건을 4/4 맞혔다.
반면 동일 언어 `Do not open the door.`→`Open the door.`와
`문을 열지 마.`→`문을 열어.`를 전체 의미/행동에서 보존으로 판정했다.
모델은 기본 분류를 수행하지만 현재 질문으로 의미 비교를 안정적으로 수행하지 못했다.
이는 모든 Laya 모델/질문/학습 방식이 실패한다는 증거는 아니다.

시간은 토크나이징·여섯 질문·CUDA 동기화를 포함한 호출 전체 시간이다.
최종 SDK 로딩 15.091초(이전 두 실행 39.746초/6.959초)는 별도이며 warmup도
제외했다. 로딩 수치는 Python/라이브러리 import와 파일 검증/복사 시간을 포함하지 않는다.
세 실행의 profile별 호출 중앙값은 약 0.033~0.047초 범위였다. 환경 변동이
있으므로 단일 실행의 수치를 고정 지연으로 약속하지 않는다. 최종 CPU fallback 계수 0.
PyTorch peak allocated 1,588,273,152 bytes, reserved 1,633,681,408 bytes.
이는 프로세스 전체 VRAM이나 Whisper/Qwen 동시 사용 메모리 측정이 아니다.

## 결정과 남은 범위

현재 다국어 checkpoint와 검증 질문을 자막 차단/자동 재번역/종료 제어에
연결하지 않는다. 빠른 판단은 확인했지만 핵심 오역을 많이 통과시키고 순서
민감도가 있다. 확률 임계값만 높이는 것으로 놓친 오류의 복구를 보장할 수 없다.
단순 사족/길이/출력 한도는 별도의 결정적 코드로 제어할 수 있다.

다음 Laya 실험을 한다면 구체적인 의미 선택지나 도메인 학습을 별도 자료로
평가해야 한다. 이번 자료로 튜닝하고 같은 자료에서 개선을 주장하지 않는다.
실제 자막/음성 지연, ASR/번역 동시 GPU 사용, 취소/큐, Mac은 미실행이다.
앱/worker/IPC 변경 없음. Python AST·JSON·PowerShell 구문 및 `git diff --check` PASS.
