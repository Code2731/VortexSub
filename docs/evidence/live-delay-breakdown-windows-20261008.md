## 긴 표시 대기

51개 첫 줄 중 20개가 1초 넘게 기다렸다.
segment 11/unit 0은 4.421초, segment 8/unit 0은 4.271초,
segment 9/unit 0은 4.268초였다.
단위 갱신은 대기열에서 합쳐졌다. 오래된 줄을 보호하는 동안 새 단위가 기다렸다.
segment 8과 9는 BothLinesProtected→LowerLineProtected→BothLinesProtected를 거쳤다.
이는 번역 처리 완료 후에도 여러 차례 읽기 보호를 기다린 사례다.

BothLinesProtected 닫힌 구간 36건의 중앙값은 1.034초, P95는 2.589초였다.

기존 단위의 남은 내용·수정과 새 단위가 같은 두 슬롯을 사용한다.
이 구조가 긴 대기와 연결된다. 로그에는 문장이 없으므로 의미 중복·오역은 판정하지 않았다.
