# 긴 문장과 부분 자막 수정 화면 확인

날짜: 2026-10-05. 환경: Windows x64, .NET 10, 화면 배율 125%.

## 변경과 범위

실제 모델 화면 캡처에 `-Revisions`를 추가했다. `-Sequence`와 별도로 실행한다.
설치된 Hy-MT2 모델과 실제 HTTP 번역을 사용한다. VAD·ASR 입력은 모의다.
오버레이 폭은 420 DIP다. 개인 설정은 저장하지 않는다.
부분 전사와 안정된 부분 번역을 켠 뒤 실제 worker 세션을 시작한다.
읽기 시간과 자막 표시 정책은 변경하지 않았다. Laya 기능은 사용자 지시에 따라 진행하지 않는다.

긴 확정 문장 한 개를 먼저 표시한다. 이후 다음 원문을 전달한다.

| 예정 시각(초) | 종류 | 원문 |
|---:|---|---|
| 14.0 | 부분 | Leave the door open. |
| 14.8 | 부분 반복 | Leave the door open. |
| 15.8 | 부분 확장 | Leave the door open. Wait outside. |
| 16.6 | 부분 반복 | Leave the door open. Wait outside. |
| 17.2 | 최종 수정 | Keep the door closed. Wait outside. |

실제 전달 시각·원문 상태·번역 상태·revision과 줄 전환은 `revisions.json`에 기록한다.
36초 동안 약 0.05초 간격으로 상태를 관찰한다. 화면은 전환 시 최대 32개 저장한다.

## 실행 명령

저장소 루트에서 실행한다. 설치 모델·b11146 런타임과 기본 worker가 필요하다.

```powershell
$env:AVALONIA_TELEMETRY_OPTOUT = '1'
$env:NUGET_PACKAGES = Join-Path $PWD '.nuget/packages'
dotnet build apps/EchoSub.Desktop/EchoSub.Desktop.csproj --no-restore
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/capture-model-ui.ps1 -NoBuild -Revisions -OutputDirectory benchmarks/results/ui-model-revisions-active-20261005
```

앱 빌드는 경고 0개, 오류 0개였다.
최종 실행 원본은 Git 제외 `benchmarks/results/ui-model-revisions-active-20261005/`에 보관한다.
화면은 `revision-*.png`다. 다른 PC로 Git을 통해 전달되지 않는다.

## 예비 관찰

첫 실행 `ui-model-revisions-20261005`은 36.036초, 상태 표본 573개, 화면 14개였다.
긴 번역은 6개 줄에 나뉘어 꼬리까지 표시됐다. 줄 위치는 36.8·84로 유지됐다.
부분 번역은 `문을 열어 두세요.`를 표시한 뒤 `밖에서 기다리세요.`를 이어 표시했다.
최종 번역은 `문을 닫고 밖에서 기다려 주세요.`였다.
이 실행의 최종 수정은 21초에 입력해 이전 자막의 표시 기한이 이미 끝나 있었다.
보이는 자막의 의미 반박을 확인하기 위해 최종 실행은 입력 간격을 위 표처럼 줄였다.
두 실행을 같은 입력 조건의 속도 비교로 해석하지 않는다.

## 최종 관찰 결과

최종 실행은 종료 코드 0이었다. 36.036초 동안 상태 표본 574개와 전환 화면 13개를 기록했다.
긴 번역은 0.56초에 도착했다. 총 6개 줄을 순서대로 표시하고 9.06초에 읽기 슬롯이 비었다.
부분 원문의 반복은 같은 세그먼트 3의 revision 1~5로 처리됐다.
부분 번역은 revision 2·4에서, 최종 번역은 revision 5에서 도착했다.

| 관측 시각(초) | 화면 상태 |
|---:|---|
| 15.23 | 위 줄: 문을 열어 두세요. |
| 16.73 | 위 줄 유지, 아래 줄: 밖에서 기다리세요. |
| 17.29 | 최종 원문이 기록에 도착. 기존 표시 줄 유지 |
| 17.47 | 최종 번역 완료. 기존 표시 줄 유지 |
| 17.78 | 위 줄의 읽기 기한 종료. 아래 줄 유지 |
| 19.26 | 최종 번역을 두 줄에 표시 |
| 22.02 | 읽기 슬롯이 비어 있음 |

최종 번역은 `문을 닫고 밖에서 기다려 주세요.`였다.
번역 완료부터 최종 표시까지 약 1.79초의 읽기 대기가 있었다.
현재 `CaptionLines.InvalidateSegment`는 미표시 입력과 대기를 취소하지만 보이는 줄은 유지한다.
이는 [현재 줄 표시 계약](../CAPTION_LINES.md)의 읽기 보호 정책이다.
따라서 의미가 반박된 기존 자막도 잠시 남을 수 있다. 즉시 제거됐다고 판단하지 않는다.
이 정책을 변경하지 않았다. 일반 글자 추가와 의미 반박을 구분한 후속 판단이 필요하다.

위·아래 줄의 Y 위치는 36.8과 84로 유지됐다. 표시 줄의 Run은 각각 1개였다.
최종 실행의 `revision-07`~`10`, 예비 실행의 긴 문장 화면을 직접 확인했다.
부분 내용이 늘어날 때 기존 위 줄은 유지됐다. 아래 줄은 위로 이동하지 않았다.
실행 후 모델 서버 프로세스와 임시 인증키 파일이 남지 않았다.

## 남은 범위

모의 원문 2개 구간의 관찰이다. 자연 음성, 부분 전사의 실제 정확도와 30분 사용은 남아 있다.
Avalonia 렌더를 저장했다. 운영체제 화면 합성과 표본 사이의 깜빡임은 확인하지 못했다.
미표시 내용의 무효화와 보이는 줄의 유지가 서로 다르다. 위의 최종 수정 대기를 후속 범위에 포함한다.
이번 라운드에서는 자동 테스트를 추가하거나 실행하지 않았다.
이번 소스·문서는 미커밋이다. 다른 PC에는 최신 작업이 전달되지 않았다.
