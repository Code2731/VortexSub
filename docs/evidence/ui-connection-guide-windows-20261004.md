# 번역 연결 안내와 초기 사용 흐름 (2026-10-04)

## 변경

- 초기 사용 안내를 접기·펼치기로 제공한다. 앱 실행, 장치·언어 선택,
  세션 시작, 음성 재생, 오버레이 표시 순서를 안내한다.
- 메인 화면의 **번역 설정** 버튼은 설정 탭의 번역 연결 영역으로 이동한다.
- 번역 상태를 한국어로 표시한다. 서버 연결 실패, 응답 시간 초과,
  모델·입력 방식 불일치, 인증 거부, 요청 경로 오류 등을 구분한다.
  알 수 없는 오류는 원인을 단정하지 않는다. 원래 코드는 오류 상세에 남긴다.
- 서버 주소는 전송 전에 숫자 loopback 주소, 명시적 포트, 지원 경로를 확인한다.
  worker의 주소 검증은 유지한다.
- 설정 명령 거절 안내는 상태 조회가 성공해도 유지한다. 다음 설정 시도,
  번역 끄기 성공 또는 연결 종료에서 해제한다.
- 설정 요청 수락 뒤 상태 조회 실패와 명시적 설정 거절을 구분한다.
  요청 응답을 받지 못한 경우도 적용 여부를 단정하지 않는다.
  실패를 확인한 명령만 입력 방식과 문맥 옵션을 기존 설정으로 되돌린다.

## 확인

Windows x64 앱 빌드는 경고 0개, 오류 0개로 통과했다.

```powershell
dotnet build apps/EchoSub.Desktop/EchoSub.Desktop.csproj --no-restore
dotnet run --project apps/EchoSub.Desktop --no-build --no-restore -- --ui-capture-worker J:/MyProject/VortexSub/target/debug/echosub-worker.exe --ui-capture-dir J:/MyProject/VortexSub/benchmarks/results/ui-connection-guide-final-20261004
```

명시적 모의 worker로 9개 화면 렌더를 저장하고 모두 확인했다.
기본·최소 크기, 네 탭, 설정 하단, 초기 안내 펼침, 번역 연결 영역을 포함한다.
125% 배율의 최소 창에서도 주요 자막 제어가 보인다.
초기 안내를 펼치면 본문은 세로 스크롤로 접근한다.
캡처 후 마지막 빌드는 사용되지 않는 상태 플래그 제거를 포함한다.
이 정리는 화면 내용에 영향을 주지 않는다.

## 확인 범위

화면은 실행한 앱의 Avalonia 렌더다. 운영체제 합성 화면은 아니다.
실제 서버 실패, 주소 입력, 재시도, 바로가기 클릭과 개인 설정 저장은
실행 검증하지 않았다. 오류 분류는 현재 worker 오류 계약을 기준으로 구현했다.
자동 회귀 테스트와 실제 음성·번역 처리는 미실행이다.
