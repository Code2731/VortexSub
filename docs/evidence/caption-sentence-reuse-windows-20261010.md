# 문장 재사용 계약 Windows 검증

검증일: 2026-10-10, Asia/Seoul. 결과 폴더의 날짜는 UTC다.
브랜치 `master`, 기준 HEAD `15f1db0`. 이번 변경과 이전 작업은 미커밋이다.
커밋·푸시·다른 PC 전달은 하지 않았다.

## 변경

- `CaptionSentenceReuse`에 제한된 문장 분리와 정확한 문자열 LCS를 추가했다.
- 같은 원문 범위·revision과 연속된 실제 표시 이력만 재사용 증거로 사용한다.
- 문장 수 감소·이동·중간 삽입·중복·범위 미상·원문 수정·불완전 이력에는 증거를 만들지 않는다.
- 숫자·부정 표현·공백 변경은 의미가 같다고 추측하지 않는다.
- `CaptionScheduleStore.Reuse`는 토큰·해시·현재 이력을 재검증한다. 임의 범위 완료를 거부한다.
- 새 버전의 재사용 전달도 기존 이력·문자 상한에 포함한다. 읽기 줄·기한은 변경하지 않는다.
- Desktop과 검사 프로젝트가 같은 구현을 빌드한다. 기존 표시기·오버레이 연결은 아직 하지 않았다.

본문과 조각 상한은 각각 16,384 UTF-16 단위와 64개다.
LCS 내부 셀은 최대 4,096개다. 배열은 경계 행/열을 포함해 최대 65×65다.
문장 분리는 지정한 부호·약어 규칙이다. 완전한 언어 분석이나 의미적 삭제 판정은 아니다.
호출자 후보·행렬의 메모리와 UI 비용은 실제 측정하지 않았다.

## 자동 검사

구현 전에 기존 자막 회귀를 실행했다. 이후 새 검사를 통합했다.
최종 명령은 저장소 루트 기준이다.

```powershell
& scripts/test-captions.ps1 -BaselineReport benchmarks/results/caption-regression-20261009T154645Z-08ba4925/report.json
```

최종 결과: `benchmarks/results/caption-regression-20261009T155534Z-314893d0/`.

같은 보고서 재실행은 예상 종료 코드 2로 거부했다. 파일 SHA-256이 유지됐다.
`overwrite-check.json`에 결과를 기록했다. 결과·로그·PNG는 Git 제외다.

새 검사는 교정 앞문장 배정 뒤 같은 뒷문장 재사용, 두 줄에 걸친 문장,
숫자·부정·공백 변경, 소수점·약어·CJK·이모지·따옴표와 열린 꼬리를 확인한다.
위조 해시·위조 범위·중복 소비·stale 토큰·새 세션·불완전 이력도 거부했다.
64×64 행렬 경계와 65조각 거부를 확인했다.
이력 64개 상한에서 퇴역이 발생한 뒤 추가 재사용이 거부되는지도 확인했다.
300개 발화의 교정·재사용을 가상 시계로 반복했다. 1,800초의 상태 검사다.
모든 300개 재사용을 집계했고 저장 상한을 유지했다. 정상 부하의 큐 용량 폐기는 0이었다.
실제 30분 음성 또는 프로세스 메모리 측정은 아니다.

초기 검사는 동일 전체 본문에 이미 존재하는 표시 진행 위치와 중복 재사용이 충돌했다.
기존 완료 경로를 유지하고 중복 소비 거부를 검사하도록 수정했다.
문장 순서 변경에서 trailing 공백 때문에 매칭이 사라지는 경우도 확인했다.
순서 거부만 공백을 제거해 비교하도록 보강했다. 재사용은 계속 정확한 문자열 비교다.

## 환경과 미검증

Windows x64, .NET SDK `10.0.102`, 기존 Python/Pillow와 복원한 패키지를 사용했다.
장치는 Windows 11 Home 64비트 / Ryzen 7 5800X / RTX 3080이다. GPU 추론은 실행하지 않았다.
새 모델·런타임·의존성 다운로드와 개인 설정 변경은 없다.
독립 상태 검사에는 .NET 10이 필요하다. 저장 화면 검사에는 Python/Pillow가 필요하다.
모델·캐시·보고서가 다른 PC에 전달된다고 가정하지 않는다.

후보 줄 배정·후보 화면·실제 음성·모델 추론·일반 의미 품질·OS 연속 프레임·macOS는 미검증이다.
렌더 통과는 기존 제품 표시기 범위다. 이번 구현의 실제 표시 지연 개선은 아직 측정하지 않았다.
Rust·IPC·전체 `scripts/check.ps1`은 이번에 실행하지 않았다. 해당 소스는 변경하지 않았다.
수동 재시험은 요청하지 않았다.
