# 실제 번역의 두 줄 연속 표시

날짜: 2026-10-05. 환경: Windows x64, .NET 10, 화면 배율 125%.
이 기록은 [한 문장 화면 확인](ui-model-capture-windows-20261005.md)의 후속이다.

## 작업

모델 화면 캡처에 `-Sequence` 옵션을 추가했다.
설치된 Hy-MT2와 실제 HTTP 번역을 사용한다. 음성 입력은 모의 확정 원문이다.
짧은 문장 6개를 약 0.65초 간격으로 보낸다. 실제 UI 시계로 24초간 관찰한다.
줄 내용이 바뀔 때 화면을 저장한다. 줄의 위치·구간 식별자·Run 수도 기록한다.
번역 도착과 첫 줄 표시를 별도로 기록한다. 읽기 대기는 두 시각의 차이다.
화면은 최대 24개로 제한한다. 관찰 실행은 24초로 제한한다.
화면 저장과 약 0.05초 표본 간격 때문에 물리 화면의 모든 프레임을 기록하지는 않는다.

## 실행

저장소 루트에서 실행한다. 이전 확인과 같은 모델·런타임·기본 worker가 필요하다.

```powershell
$env:AVALONIA_TELEMETRY_OPTOUT = '1'
$env:NUGET_PACKAGES = Join-Path $PWD '.nuget/packages'
dotnet build apps/EchoSub.Desktop/EchoSub.Desktop.csproj --no-restore
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/capture-model-ui.ps1 -NoBuild -Sequence -OutputDirectory benchmarks/results/ui-model-sequence-final-20261005
```

앱 빌드는 경고 0개, 오류 0개였다.
실행 원본은 Git 제외 `benchmarks/results/ui-model-sequence-final-20261005/`에 보관한다.
`sequence.json`에 번역·첫 표시·줄 전환을 기록한다. 화면은 `sequence-*.png`다.

## 결과

최종 실행은 종료 코드 0이었다. 24.032초 동안 382회 상태를 관찰했다.
번역 6개가 모두 도착했고 구간 2~7 모두 화면에 나타났다. 전환 화면 8개를 저장했다.
위·아래 줄의 Y 위치는 각각 36.8과 84로 유지됐다. 표시 줄의 Run은 각각 1개였다.
`sequence-01`~`06` 화면을 직접 확인했다. 먼저 나온 위 줄이 사라져도 아래 줄은 이동하지 않았다.
표본에서 관측한 각 문장의 표시 기간은 약 2.50~2.71초였다.
모델 서버와 임시 인증키는 실행 뒤 남지 않았다.

| 구간 | 앱 기록 도착까지(초) | 기록 도착 후 첫 표시 대기(초) | 첫 표시 줄 |
|---|---:|---:|---|
| 2 | 0.31 | 0.00 | 위 |
| 3 | 0.12 | 0.00 | 아래 |
| 4 | 0.13 | 1.89 | 위 |
| 5 | 0.19 | 1.14 | 아래 |
| 6 | 0.19 | 3.32 | 위 |
| 7 | 0.20 | 2.67 | 아래 |

첫 표시 대기 0.00은 같은 표본에서 기록과 표시를 관측했다는 뜻이다.
이 빠른 입력 조건에서는 번역보다 읽기 슬롯의 대기가 더 길었다.
두 줄의 읽기 시간을 지키는 동안 뒤 문장이 쌓였다. 번역 속도 저하로 해석하지 않는다.
모든 문장이 표시됐으므로 이 결과만으로 읽기 시간을 줄이지 않았다.
자연 음성의 문장 간격과 긴 문장의 표시를 함께 확인한 뒤 정책 변경을 판단한다.

## 한계와 후속

실제 번역과 UI 경로를 사용했지만 입력은 음성이 아니다. VAD·ASR은 미검증이다.
이번 입력은 짧은 확정 문장이다. 긴 문장 줄바꿈과 부분 전사의 의미 수정은 포함하지 않는다.
표본 사이의 깜빡임, 운영체제 화면 합성, 사용자의 읽기 완료는 판단할 수 없다.
24초 관찰을 30분 사용 검증으로 해석하지 않는다.
자동 테스트를 추가하거나 실행하지 않았다. 자막의 읽기 시간 정책도 변경하지 않았다.
다음은 최신 자막 정책의 상태·렌더 회귀와 장시간 사용 확인이다.
이번 변경은 미커밋이다. 다른 PC에는 아직 전달되지 않았다.
