# 자막 글꼴 크기 조절

2026-10-07. Windows x64. 로드맵의 독립적인 오버레이 작업을 진행했다.
요구 ID `UI-002`의 글꼴 크기 조절 범위다. M3 수용 완료를 의미하지 않는다.

## 변경

설정 탭의 자막 창 모양에 글꼴 크기 슬라이더를 추가했다.
범위는 18~48 DIP, 기본값은 26이다. 1 단위로 조절한다.
자막을 중지한 Idle 상태에서 조절할 수 있다. 진행 중인 읽기 줄을 재배치하지 않는다.
접근성 이름은 `자막 글꼴 크기`다. 설정 탭의 키보드 이동 순서에도 포함했다.

번역 두 줄과 폭 측정에 같은 글꼴 크기를 적용한다.
원문 크기와 번역 줄 높이는 기존 26 기준 비율을 유지한다.
글꼴 변경 시 폭 측정 캐시를 비운다. 큰 글꼴에서는 창의 최소 높이도 늘린다.
위치 초기화도 최소 높이를 따른다. 원문이 길면 기존 스크롤 경로를 사용한다.

`DesktopPreferences.OverlayFontSize`로 저장·복원한다.
기존 버전 1 설정에 필드가 없으면 26을 사용한다.
읽은 값이 범위를 벗어나면 제한한다. 유한하지 않은 값은 기본값을 사용한다.
모의/관찰 실행은 기존 정책에 따라 개인 설정을 읽거나 저장하지 않는다.
