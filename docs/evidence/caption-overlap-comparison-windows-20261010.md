고정 줄 위치·배출·저장 화면의 글자 유지도 검사한다.
두 표시기의 프레임에 발화 ID를 기록한다. 최초 Done 입력 이후 같은 발화가 첫 줄에 배정되는 시각을 비교한다.
FirstLine의 단위/버전 집계 차이는 이 비교에 사용하지 않는다.
같은 발화 내 교정 버전의 최초 표시 시각은 아직 별도로 측정하지 않는다.
